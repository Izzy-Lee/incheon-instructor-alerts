# 지원예정 공용 저장 + 첨부 드라이브 저장 설정 (처음 한 번)

⭐ 지원예정 표시를 모든 기기에서 같이 보고, ⭐ 공고의 첨부파일(공고문·지원서)을
구글드라이브 「강사지원DB/공고첨부」에 자동으로 저장하기 위한 설정이에요.

## 1. Apps Script 만들기
1. https://script.google.com → **새 프로젝트**, 이름: `인천 강사공고 지원예정`
2. `Code.gs` 내용을 지우고 이 폴더의 `Code.gs` 를 통째로 붙여 넣고 저장
3. 위쪽 함수 목록에서 **setup** 선택 → **실행** → 권한 허용
4. **실행 로그**에 나온 `UPLOAD_TOKEN` 값을 복사해 둠 (시트·폴더 주소도 같이 나옴)

## 2. 웹 앱으로 배포
1. **배포 → 새 배포 → 유형: 웹 앱**
2. 실행 사용자: **나**, 액세스 권한: **모든 사용자**
3. 나온 웹 앱 주소(`https://script.google.com/macros/s/…/exec`)를 복사

## 3. 저장소에 연결
1. `docs/config.js` 의 `window.MARKS_API = '';` 따옴표 안에 웹 앱 주소 넣기
2. GitHub 저장소 **Settings → Secrets and variables → Actions → New repository secret**
   - 이름 `UPLOAD_TOKEN`, 값: 1-4에서 복사한 값

끝. 이제 공고 페이지에서 ⭐를 누르면 30분 안에 첨부가 드라이브에 저장되고,
페이지에 「📁 드라이브에 저장됨」 링크가 생겨요.

## 참고
- 표시 기록은 구글시트 「인천 강사공고 지원예정」(강사지원DB 폴더)에 쌓여요. 시트에서 지워도 돼요.
- 첨부를 못 받으면 시트 `note` 칸에 이유가 적히고 3번까지 다시 시도해요.
- Code.gs 를 고친 뒤에는 **배포 → 배포 관리 → 편집 → 버전: 새 버전**으로 다시 배포해야 반영돼요.
- 특정 공고에서 첨부를 잘 찾는지 보려면: Actions → 지원예정 첨부 드라이브 저장 → Run workflow → 공고 주소 입력.
