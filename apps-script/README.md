# 지원예정 공용 저장 + 첨부 드라이브 저장 설정 (처음 한 번)

⭐ 지원예정 표시를 모든 기기에서 같이 보고, ⭐ 공고의 첨부파일(공고문·지원서)을
구글드라이브 「강사지원DB/공고첨부」에 자동으로 저장하기 위한 설정이에요.

## 흐름
1. 공고 페이지에서 ⭐ → Apps Script 웹앱이 구글시트에 기록
2. GitHub 봇(30분마다)이 ⭐공고의 첨부를 받아 저장소 `inbox/` 에 올림
3. Apps Script(10분마다)가 `inbox/` 에서 가져와 드라이브 폴더에 저장, 시트에 「저장됨」 기록
4. 다음 봇 실행 때 `inbox/` 에서 지움

비밀번호나 토큰은 필요 없어요.

## 설정
1. https://script.google.com → **새 프로젝트**, 이름: `인천 강사공고 지원예정`
2. `Code.gs` 내용을 지우고 이 폴더의 `Code.gs` 를 통째로 붙여 넣고 저장
3. 함수 목록에서 **setup** 선택 → **실행** → 권한 허용 (시트·드라이브 폴더·10분 트리거가 만들어짐)
4. **배포 → 새 배포 → 웹 앱**, 실행 사용자: **나**, 액세스: **모든 사용자** → 배포
5. 나온 웹 앱 주소(`https://script.google.com/macros/s/…/exec`)를 `docs/config.js` 의 `window.MARKS_API = '';` 따옴표 안에 넣기

## 참고
- 표시 기록은 구글시트 「인천 강사공고 지원예정」(강사지원DB 폴더)에 쌓여요.
- 첨부를 못 받으면 시트 `note` 칸에 이유가 적히고 6번까지 다시 시도해요.
- 부평구(eminwon.icbp.go.kr) 첨부는 해외 서버(GitHub)에서 접속이 막혀 있어 못 받을 수 있어요.
- Code.gs 를 고친 뒤에는 **배포 → 배포 관리 → 편집 → 버전: 새 버전**으로 다시 배포해야 반영돼요.
- 특정 공고에서 첨부를 잘 찾는지 보려면: Actions → 지원예정 첨부 드라이브 저장 → Run workflow → 공고 주소 입력.
