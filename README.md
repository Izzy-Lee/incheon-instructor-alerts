# 인천 강사공고 봇

매일 아침 6시 43분과 오후 5시 43분(한국 시간)에 인천 공공기관·군·구청 채용 게시판을 돌면서 **강사 공고만** 골라 GitHub 이슈로 알려줍니다.

- **알림**: 이 저장소의 Issues 탭. 새 이슈가 올라오면 GitHub 메일·앱 알림이 와요.
- **전체 목록**: https://izzy-lee.github.io/incheon-instructor-alerts/
- **날짜별 기록**: `reports/` 폴더

- **⭐ 지원예정**: 목록 페이지에서 ⭐를 누르면 모든 기기에 같이 저장되고, 그 공고의 첨부(공고문·지원서)가 1시간 안에 구글드라이브 「강사지원DB/공고첨부」에 자동 저장돼요. 처음 설정은 `apps-script/README.md`.

## 고치고 싶을 때

| 하고 싶은 것 | 고칠 파일 |
|---|---|
| 수집할 사이트 추가·삭제 | `sources.yaml` |
| 강사 공고로 볼 단어, 뺄 단어, 내 분야 단어 | `keywords.yaml` |
| 실행 시간 | `.github/workflows/daily.yml` 의 `cron` (UTC 기준, 한국보다 9시간 느림) |

지금 바로 돌려보려면 **Actions → 인천 강사공고 수집 → Run workflow**.

## 수집 사이트

인천광역시교육청 채용공고, 늘봄허브 학교별 요청 공고(인천), 나라일터(인천), 인천일자리플랫폼 공공채용(잡알리오·클린아이 포함), 미추홀·연수·남동·부평·서해·검단·영종구, 강화·옹진군 채용공고 게시판.

계양구·제물포구 게시판은 해외 서버(GitHub)에서 접속이 막혀 꺼 두었어요(`sources.yaml`에 주석으로 남아 있음).

같은 실행에서 인천 지원사업·공모 사이트 10곳(인천관광공사, 콘텐츠코리아랩, 테크노파크, 드림파크문화재단, 관광기업지원센터, K-Startup, 인천문화재단 3개 게시판, 미추홀구립도서관)도 확인해요.
- 목록: https://izzy-lee.github.io/incheon-instructor-alerts/grants.html
- 알림: Issues 탭의 「지원사업」 라벨
- 고칠 파일: `grants/sources.yaml`(사이트), `grants/keywords.yaml`(걸러내기·분야)

## 지원사업 예고 캘린더

올해 실제 공고(지원사업 게시판의 지난 13개월 글)와 K-Startup 「중앙부처 및 지자체 창업지원사업 통합공고」 표의 공고시기로 다가올 1년의 공고를 예고해요.
- 구글 캘린더 구독 주소: https://artable.me/incheon-instructor-alerts/forecast.ics (구글 캘린더 → 다른 캘린더 + → URL로 추가)
- 🔮 예고(작년 기준 추정) · 🗓 계획(올해 통합공고) · ✅ 공고 떴음 · ⏰ 마감
- 예고일 10일 전~25일 후에는 그 게시판을 3시간마다 확인해요 (`.github/workflows/watch.yml`).
- 새 해 통합공고가 올라오면 자동으로 받아 계획을 바꿔요.

## 나라장터 입찰공고 (bids.html)

- 매일 같은 시간(06:43·17:43)에 나라장터 입찰공고 목록을 공고명 검색어로 조회해 **아직 마감 안 된 올해 공고**만 남겨요.
- 설정: `bids/sources.yaml`(검색어·지역), `bids/keywords.yaml`(제외어·분류).
- 수요기관이 인천·근교(30분 거리)면 분야별로, 그 밖의 지역은 미술·굿즈·캐릭터처럼 딱 맞는 것만 「전국 (지역제한 확인)」으로 보여 줘요.
- 공사·엔지니어링·IT·수학여행 위탁은 빼고, 학교 방과후·늘봄 위탁은 따로 묶어요.
- 새 공고가 있으면 `나라장터` 라벨 이슈로 알려요. 투찰은 나라장터에서 직접 로그인해서 해야 해요.
